## 0. 役員向けエグゼクティブサマリ

### 何を決めたいか
「**顔を出さない代わりに何を見せるか**」の様式選定。サイト全体で 1〜2 様式に絞らないと、ページごとにバラついて素人サイトに見える。

### 上司・経営層の希望（議事より）
- メンバー紹介を **イラストや後ろ姿** など顔出しに頼らない形に
- コールセンター発祥なので **顔出ししない方向性** がコンテキストとして強い
- 学歴・経歴ではなく **会社の独自性** で勝負したい

### 推奨する基本様式（採用ページ例外あり）

| ページ | 推奨様式 | 補完情報 |
| --- | --- | --- |
| **メンバー一覧 / 個別** | **線画イラスト**（統一トーン） | テキストインタビュー + 担当事業へのリンク |
| **トップページ** | **数値タイポ + 環境ショット** | 集合・組織として語る |
| **コールセンター（採用兼）** | **環境ショット**（オフィス・現場・後ろ姿） | 入社者コメント（顔なし）+ 数値 |
| **AI OPS** | **データ可視化 / 抽象アニメ** | 導入企業数 + 自動化工数の数値 |
| **財務コンサル** | **静謐な編集ショット + 第三者推薦** | 累計実行額 + 取引先カテゴリ |
| **採用ページ全般** | 環境ショット + 入社者の声 | コールセンター採用は「**顔出し OK の例外**」を検討 |

### なぜ顔出しなしがブランド資産になるか
1. **競合（大手出身マーケター）と土俵を変える** — 経歴比較から降りる
2. **コールセンター発祥の文脈と整合** — 「顔は見えないが、価値は届く」は GIFT のメタファー
3. **メンバー入れ替わりに強い** — 撮影し直しが不要、長期運用に強い
4. **採用フィルターになる** — 「個人のスター性ではなく組織で価値を出す」というカルチャー宣言

### リスクと対策
- **リスク 1**: 財務コンサル領域で「顔が見えない＝信頼できない」と読まれる
- **対策**: 累計実行額・取引先カテゴリ・第三者推薦コメントを強く出す
- **リスク 2**: コールセンター採用で応募率が下がる
- **対策**: 採用ページのみ顔出し OK の **例外設計**（複数選択肢を Section 5 で提示）

### 次のステップ
1. 役員レビューで様式合意
2. Phase D で素材発注書（イラスト発注先・撮影プラン・データ可視化制作プラン）に展開

### 1.2 各様式の詳細

#### 様式 1: 後ろ姿動画

**特徴**: メンバーの後ろ姿（歩く、座る、画面を見る等）を数秒の動画で

**長所**:
- 動きで「品質感」が出る → 上司が neu-ad に対して感じた効果と一致
- 個人を特定しないが、人の存在は感じさせる

**短所**:
- 撮影が高負荷（プロカメラマン + 演出）
- メンバー入れ替えで全員撮り直し
- ロード重い → パフォーマンス劣化リスク

**実例**: 国内 B2B では明確な事例未確認（neu-ad の team も実機未検証）

**GIFT への適用**: メンバー一覧で全員に動画を当てるのは現実的でない。**Hero やトップの装飾動画として 1〜2 カット使う** のが現実解

---

#### 様式 2: シルエット静止画

**特徴**: 黒抜き or 単色塗りつぶしのシルエット。共通アイコンとして使う場合も

**長所**:
- 制作・更新が最も楽
- 完全な匿名化が可能
- ミニマル・知的な印象

**短所**:
- 親しみが出にくい
- 全員同じシルエットだと記憶に残らない

**実例**: rebita 20th の外部関係者コメント欄

**GIFT への適用**: **取引先の推薦コメント欄** や **応募者の声** など、本人を匿名化したい場面で活用

---

#### 様式 3: イラスト（似顔絵タッチ）

**特徴**: 線画 + 軽い彩色で本人らしさを残しつつ匿名化（Ra-tel / イイ人型）

**長所**:
- 親しみが最大
- 個性は出るが顔写真ほど経歴を引きずらない
- メンバー追加時もイラストレーターに発注すれば対応可

**短所**:
- イラストレーターのタッチに左右されるため、**1 人に統一発注しないとバラつく**
- B2B コーポレートでは軽すぎる印象になることも

**実例**: Ra-tel, イイ人, 小規模制作会社多数

**GIFT への適用**: **コールセンター採用ページの入社者コメント** など、親しみを優先する場面に最適

---

#### 様式 4: イラスト（フラットスタイル）

**特徴**: 平面的・幾何学的なイラスト。色面で構成（講談社採用 / バケモノ型）

**長所**:
- ブランドの世界観を作りやすい
- フラットだから情報密度が低く、本文が読みやすい
- メンバー追加時の制作も比較的楽

**短所**:
- 「個人の個性」は出にくい（全員同じテンプレに見える）
- カラーパレットが事業層と衝突しないよう設計が必要

**実例**: 講談社 2026 採用, バケモノ採用

**GIFT への適用**: **メンバー一覧** の主軸候補。個別ページのアイキャッチとして統一感のあるフラットイラストを採用

---

#### 様式 5: イラスト（線画 / モノクロ）★ メンバー紹介の推奨

**特徴**: 細い線で描かれたモノクロ寄りのイラスト。エッジが効いた知的な印象

**長所**:
- B2B コーポレートに違和感なく馴染む
- 事業層のメインカラーが何でも調和する
- 更新時、新メンバーの線画を追加するだけ
- 「アート性 × 知的」の両立

**短所**:
- イラストレーターの選定が重要（タッチが弱いと安く見える）

**実例**: 海外のクリエイティブ系コーポレート、編集系メディアに多い

**GIFT への適用**: **メンバー一覧の主軸として最推奨**。理由は (a) 案 B のメタ層と整合 (b) 事業ごとのメインカラーと衝突しない (c) 知的・誠実な印象が GIFT の事業（特に財務）と整合

---

#### 様式 6: イラスト（動物・アバター）

**特徴**: GEAR8 型（動物キャラクター）, みずほ FG 型（ドット絵アバター）

**長所**:
- 強い個性が出る
- ゲーミフィケーション要素を入れやすい

**短所**:
- B2B コーポレートの信頼感とは相性が悪い
- 財務コンサルでこれをやると「ふざけた会社」と読まれる

**GIFT への適用**: **不採用推奨**。GIFT の事業領域とトーンが合わない

---

#### 様式 7: 手元・道具ショット

**特徴**: メンバーの手・キーボード・電話・ヘッドセット等、作業中のオブジェクトを撮影

**長所**:
- 「働いている」感が伝わる
- プロカメラマンに発注すれば、写真 1 枚で高品質感が出せる
- 動画ほどコスト高くない

**短所**:
- メンバー特定要素として弱い
- 「またこの種の写真か」になりがち

**GIFT への適用**: **コールセンター事業ページの導入カット** や **AI OPS の作業風景** に部分採用

---

#### 様式 8: 環境ショット（現場・空間）★ コールセンター採用の推奨

**特徴**: オフィス・コールセンター現場・打ち合わせ風景を、人物特定できないアングルで撮影

**長所**:
- 「実在する会社」「リアルな現場」感が強い
- 採用ページで「働く環境」が伝わる
- 桐山組のように、これだけで採用サイトが成立する例あり

**短所**:
- 写真の質に直結（プロカメラマン必須）
- オフィスの綺麗さに依存

**実例**: 桐山組 採用

**GIFT への適用**: **コールセンター採用ページの主軸として最推奨**。応募者は「どんな環境で働くか」を最も知りたいので、現場の解像度が高い写真は応募率に直結

---

#### 様式 9: 音声 + 文字（顔なしインタビュー）

**特徴**: メンバーの肉声 + 文字書き起こし、本人は映さない

**長所**:
- 「個人の声」が直接伝わる強さ
- 編集メディア感が出る

**短所**:
- 制作・収録の負荷
- アクセシビリティ対応（字幕必須）

**GIFT への適用**: **AI OPS / 財務 の事業ページ** で、お客様の声 or メンバーの考え方を伝える文脈で部分採用

---

#### 様式 10: データインフォグラフィック ★ AI OPS の推奨

**特徴**: 数値・グラフ・組織構成・KPI で組織を可視化（ALH 採用型）

**長所**:
- B2B、特にテック・データ系企業との相性が抜群
- 個人ではなく組織で語る
- 国の平均との比較等で **客観的な強み** を可視化

**短所**:
- データを集めて言語化するコストが高い
- 数値が更新されないと古びる

**実例**: ALH 採用インフォグラフィック

**GIFT への適用**: **AI OPS 事業ページの主軸として最推奨**。テック青カラーと整合し、AI 事業の「データドリブン」イメージを強化

## 2. ページ別の様式割り当て（推奨）

### 2.1 各ページの主軸様式

| ページ | 主軸様式 | 副次要素 | 理由 |
| --- | --- | --- | --- |
| **トップ** | 数値タイポ + 環境ショット | 後ろ姿動画 1 カット（Hero） | 「集合・組織で語る」。動画は装飾に留め、過剰演出を避ける |
| **コールセンター事業（法人向け）** | 環境ショット + データ | — | 信頼性 = 規模感 + 現場感 |
| **コールセンター採用（個人向け）** | **環境ショット**（メイン） + イラスト（入社者コメント） | 例外設計検討（後述） | 桐山組モデル。応募率優先 |
| **AI OPS** | **データインフォグラフィック** + 抽象アニメ | 環境ショット 1〜2 カット | テック信頼性 = 数値 + ビジュアル |
| **財務コンサル（提携先窓口）** | 静謐な編集ショット + シルエット型推薦コメント | 第三者推薦 | 重厚・信頼 = 第三者証跡 |
| **メンバー一覧** | **線画イラスト**（全員統一タッチ） | テキストインタビュー | 知的・親しみのバランス |
| **メンバー個別** | 線画イラスト（拡大版） | テキストインタビュー + 担当事業リンク | 個別の物語を文字で伝える |
| **採用一覧（コールセンター以外）** | 環境ショット + 入社者の声 | — | リアル感 |
| **会社概要 / About** | 環境ショット + 数値タイポ + 沿革タイムライン | — | 「会社」を語る |

### 2.2 様式の絞り込みロジック

サイト全体で使う様式を **3 つに絞る**:

1. **線画イラスト**（メンバー紹介の主軸）
2. **環境ショット**（採用・コールセンター・財務の主軸）
3. **データインフォグラフィック**（AI OPS 主軸 + トップの数値タイポ）

これら 3 つに副次要素として **後ろ姿動画 / シルエット / 手元ショット** を装飾的に配置。10 様式すべてを使うと統一感が崩壊するため、**主軸 3 + 副次 3** に制限。

## 4. なぜ「顔出しなし」がブランド資産になるか — 役員説明用ロジック

### 4.1 ロジック構造

```
（前提）競合（大手出身マーケター系）は顔と経歴で勝負している
        ↓
（GIFT の選択肢）同じ土俵で勝つ / 土俵を変える
        ↓
（戦略判断）土俵を変える方が勝率が高い
        ↓
（具体策）「顔出しなし」を打ち出す
        ↓
（リスク）信頼感の低下
        ↓
（対策）数値・第三者証跡・推薦コメントで補完
        ↓
（副次効果）コールセンター発祥の文脈と整合 / メンバー入れ替えに強い / カルチャー宣言になる
```

### 4.2 想定される役員質問への回答

| 質問 | 回答 |
| --- | --- |
| Q. 顔がないと不審に映らないか | A. 数値・受賞・取引先カテゴリ・推薦コメントで補完。財務領域だけ慎重に運用 |
| Q. 採用での説得力は大丈夫か | A. コールセンター採用ページは例外設計を検討（後述）。それ以外は環境ショット + 入社者の声で十分 |
| Q. メンバー個性は出せるか | A. 線画イラスト + テキストインタビューで十分。むしろ写真より深く伝わる |
| Q. 競合差別化として弱くならないか | A. 逆。**全員顔出しの中でこちらが顔なし** だから差別化が機能する |
| Q. 一時的なトレンドではないか | A. 顔出しなし採用サイトは増加傾向。匿名性・プライバシー文脈とも整合 |

### 4.3 「やる/やらない」の判断材料

| やる派の根拠 | やらない派の根拠 |
| --- | --- |
| 競合との明確な差別化 | 業界慣習からの乖離リスク |
| メンバー入れ替えに強い | 「不審」と読まれる可能性 |
| カルチャー宣言になる | 既存メンバーに説明が必要 |
| 採用で「個人スター不要」のメッセージ | 採用応募率への影響不明 |

**やる派の方が中長期的なメリットが大きい** が、**コールセンター採用ページは例外設計** が必要。

## 5. コールセンター採用ページの例外設計

### 5.1 論点

コールセンター採用は応募率が KPI 直結。**完全顔出しなし vs 一部顔出し OK** で判断が必要。

### 5.2 選択肢

#### 選択肢 A: 完全顔出しなしで貫く

- **見せ方**: 環境ショット + 入社者の **匿名コメント**（音声 or テキスト）+ 入社後イラスト
- **長所**: ブランドの一貫性
- **短所**: 応募率が他社並みになりにくい

#### 選択肢 B: 入社者のみ顔出し OK（コメント付きで本人同意ベース）

- **見せ方**: 環境ショット主軸 + 入社者の顔写真 1〜2 名（限定的）
- **長所**: 「実在する人がここで働いている」感
- **短所**: ブランド統制で例外を作ることになる

#### 選択肢 C: 後ろ姿動画 + 音声インタビュー

- **見せ方**: 入社者の後ろ姿で働く様子の動画 + 肉声
- **長所**: 顔出しなしを貫きつつリアル感
- **短所**: 動画制作コスト

### 5.3 推奨

**選択肢 C → 段階的に B へ移行可** を推奨。

- まず C（後ろ姿動画 + 音声）で **顔出しなし方針を貫く**
- 半年後、応募率データで効果検証
- 不足なら B（限定的顔出し）に **段階的に拡張** する設計

## 6. イラストの様式絞り込み（メンバー紹介）

### 6.1 候補比較

| 様式 | タッチ例 | GIFT 適合度 |
| --- | --- | --- |
| 似顔絵タッチ（Ra-tel 型） | 線 + 軽い彩色、本人らしさ残す | △ コールセンター採用には合うが財務には軽すぎる |
| フラットイラスト（講談社型） | 平面・幾何学的・色面構成 | ◯ 親しみと知的のバランス |
| **線画モノクロ**（編集メディア型） | 細い線、最小限の彩色 | ◎ B2B コーポレートに最適。事業層カラーと衝突しない |
| 動物・アバター型 | キャラクター化 | × 財務に合わない |

### 6.2 推奨様式: 線画モノクロ + アクセント色 1 点

- 全メンバー **同一イラストレーター** に統一発注（タッチのバラつき防止）
- ベースは線画モノクロ、**メンバーの担当事業のメインカラー** をアクセント 1 点だけに使う
  - 例: コールセンター担当 → アクセントが暖色 / AI OPS 担当 → アクセントがテック青
- これにより、**メンバー一覧ページで担当事業が視覚的に分かる**

### 6.3 イラストレーター発注時の指示書骨子（Phase D 用）

- タッチ: 線画 + 1 色アクセント
- スタイル: 編集メディア・知的・誠実
- 参考: （要追加発掘）
- 納品形式: SVG または高解像度 PNG（背景透過）
- 構図: 上半身 / 顔は描画 OK だが本人特定不能なレベル（特徴を抑える）
- 数: 現メンバー 8 名 + 予備 5 名分のテンプレ
- メインカラー使用: 担当事業のアクセント 1 点

## 7. 失敗パターンの予防

### 7.1 やってはいけないこと

| アンチパターン | 理由 |
| --- | --- |
| 様式を 5 つ以上混在 | 統一感が崩壊し、素人サイトに見える |
| イラストレーターを複数人に発注 | タッチがバラついて安く見える |
| 動画 + イラスト + 写真をメンバー一覧で混在 | サイト全体のリズムが崩壊 |
| シルエットを大量に使う | 「個性が無い」と読まれる |
| データだけでメンバーを表現 | 「冷たい」「機械的」と読まれる |

### 7.2 統一の原則

> **1 ページ内の人物表現は 1 様式に統一する**。
> 別ページで違う様式を使うのは OK だが、各ページ内では揃える。
