## 1. 上司の指示要点（解釈）

打ち合わせで出た発言を、ブランド・サイト戦略の言葉に置き換えると以下の 6 点に集約される。

| # | 指示の要点 | 翻訳（戦略言語） |
| --- | --- | --- |
| 1 | 画質低いと「無料っぽい」 | **クオリティ＝信頼性の代理指標**。素材・タイポ・余白すべて高単価制作レベルに |
| 2 | コールセンター→IT/AI への成長に合わせたリブランド | 単なる UI 刷新ではなく **企業フェーズの転換を視覚化** する |
| 3 | 学歴・経歴で比較されない見せ方 | 競合（大手出身マーケター）と **比較土俵を変える**。経歴ではなく "事業の独自性" と "結果" で勝負 |
| 4 | 役員から「丸めて」と言われるくらい尖る | **保守的な業界慣習からの離脱**。標準的 IT コーポレートサイトの真逆を狙う |
| 5 | 顔出ししないブランディング | **匿名性をブランドの武器に**。コールセンター起源の文脈で正当化可能 |
| 6 | 事業ごとにトーン分け（AI = テック青 等） | **マルチブランド構造**。1サイトの中に複数ブランドのトーンを共存させる |

## 2. 戦略的に "強い" 決定（評価）

打ち合わせで出た方向性のうち、**特に競合優位を生み得る** ものを評価する。

### A. 「顔出しなし」ブランディング — ★強い

**なぜ強いか**:
- 競合（大手コンサル系・マーケター系）は **必ず人物写真と経歴で勝負する**。同じ土俵に乗らない選択は強い差別化。
- 「コールセンター = 顔が見えない」を **後ろ向きの制約 → ブランドの様式美** に転換できる。
- メンバー入れ替わりに強い（写真撮影し直しが要らない）。
- 採用面でも「個人のスター性ではなく組織で価値を出す」という明確なメッセージになる。

**リスク**:
- 「顔を出さない＝信頼できない」と読まれる可能性（特に財務コンサル領域）。
- 「神秘性」と「不透明さ」は紙一重。**見せないものを補う情報** が必須（実績数字・取引社数・第三者証跡）。

**勝ち筋**:
- イラスト / 後ろ姿 / 手元 / シルエット / 動画（背中・歩く・話す）の **様式を1つに統一**。バラつくと安っぽくなる。
- 顔の代わりに **声・言葉・数字** で人を伝える。インタビュー記事や音声引用が効く。

### B. 事業ごとのトーン分け — ★中（ただし設計次第で強い）

**なぜ強いか**:
- AI OPS / コールセンター / 財務 はそれぞれ**意思決定者と読み筋が違う**。一律のトーンは結局誰にも刺さらない。
- AI 事業を独立トーンで打ち出すことで、**「コールセンター会社が DX もやってます」という弱い見え方を避けられる**。

**リスク（重要）**:
- トーンを完全に分断すると **コーポレート全体のブランド一貫性が崩壊** する。
- 「同じ会社のサイトに見えない」状態は数百万のサイトでは絶対に起きない。

**勝ち筋（必須）**:
- **メタブランド層**（コーポレート全体）と **事業ブランド層**（各事業ページ）を構造として分離する。
- メタ層は共通: ロゴ / グリッド / 文字組 / フッター / ナビ
- 事業層は可変: メインカラー / モーション / 写真トーン
- 例: Apple サイトの中で `/business`, `/education`, `/music` がそれぞれ違う表情を持つが、Apple であることは一貫している。これが目指す姿。

### C. 「尖りに尖って後で丸める」 — ★中

**良い面**:
- 制作の現場では正解。**最初から丸めると凡庸が確定する**。

**注意点**:
- 「尖り」が **デザイナーの自己表現の尖り** になりがち。これは無価値。
- 目指すべきは **戦略上の尖り**:
  - 競合が誰もやっていない構造（例: トップ全画面動画、顔なし全身イラスト）
  - 業界慣習を意図的に破る（例: IT系定番の「実績ロゴ羅列」をやらない）
- 役員に「丸めて」と言われた時、**何を守って何を譲るか** を事前に決めておく必要あり。

### D. ストーリーテラー型構成 — ★強い

**なぜ強いか**:
- 「トップ → 各事業ページ」が **連続した物語** になっていれば、サイトの体験そのものが差別化要因になる。
- これこそが「数百万かけたサイト」の本質。テンプレ的な「会社概要 / 事業 / お問い合わせ」の並列ナビでは作れない。

**実現するために必要なもの**:
- トップページの章立てを **ヘッダーナビと連動** させる（既に上司発言にある通り）
- 各事業ページへの遷移が "次章" の感覚になる演出（スクロール継続感、動画継承等）
- 共通する視覚モチーフ（後述の "顔なし様式" や色のグラデーション）が章を跨いで現れる

## 3. 検討すべき緊張関係（要決断事項）

打ち合わせで方向性は出たが、**実装に進む前に解消すべき矛盾** が複数ある。

| # | 緊張 | 決断が必要な内容 |
| --- | --- | --- |
| 1 | **顔出しなし vs 財務コンサルの信頼性** | 財務領域で顔を見せないと不審に映るリスク。代替の信頼根拠（実績数値・第三者監査・提携先名）を出す方針を固める |
| 2 | **事業別トーン vs ブランド一貫性** | "メタ層と事業層の分離設計" を最初に決めないと、ページごとにバラバラになる |
| 3 | **尖り vs 受注/採用の現実 KPI** | 尖ったサイトが直接 CV（問合せ・応募）を下げる可能性。**KPI を「CV 数」ではなく「ブランド認知 / 第一想起」にシフトすべきか** を確認 |
| 4 | **動画活用 vs パフォーマンス / ロード時間** | 高画質動画は重い。**Largest Contentful Paint** が悪化すると Google からの流入と信頼が下がる。動画は Hero のみ等の制約が必要 |
| 5 | **メンバーページの匿名化 vs 採用での説得力** | コールセンター採用ページは "そこで働く人" が見えないと応募率に効く。**コールセンター採用ページだけ顔出し OK** という例外設計の検討 |
| 6 | **4事業ページ vs リソース** | 最大 4 ページを高品質で作るのは数百万の予算が必要。**MVP で 2 ページ → 段階リリース** か、フル展開かを決める |

## 4. 共有された参考サイトの読み解き

### `https://www.rebita.co.jp/20th/`
- リビタの 20 周年特設サイト。**周年記念サイトはコーポレートサイト本体とは別軸**。映像・スクロール演出を強めに使える文脈。
- 学べるのは「**事業横断の物語化**」「映像と文字組の組み合わせ」。
- ただしこれは **特設・期間限定の文法** なので、コーポレートサイト本体に丸ごと持ち込むと運用負荷が高い。**トップページや事業ページの一部演出** として参考にすべき。

### `https://neu-ad.jp/`（チーム紹介）
- **これがおそらく上司が一番具体的にイメージしている参照**。
- 顔出しなし／動画素材／品質感の三点セットが揃った好例。
- 学べる点（要分析）:
  - メンバー紹介の動画はどの長さ・どの構図か（後ろ姿 / 手元 / 歩く / 環境ショット 等）
  - 静止画とのバランス
  - 動画ロードのテクニック（自動再生・ループ・サイレント・低解像度プリロード）
- **次のリサーチで詳細にスクショ + 仕様分析する候補**

## 5. 即時の次アクション（リサーチ担当として）

優先度順に。

### Priority 1 — 参考サイト深掘り（neu-ad / rebita を含む）
- `docs/research/04_reference_deep_dive.md` を作成
- neu-ad.jp のチーム紹介を **動画の長さ・構図・解像度・再生方式** まで分析
- rebita 20th の **章立て構造とスクロール体験** を時系列で書き出す
- 「**顔出しなし B2B サイト**」を国内外から追加で 5〜10 件発掘（広告代理店・ブランディングファーム・ステルス系スタートアップに多い）

### Priority 2 — マルチブランド構造の設計案
- メタ層 / 事業層の分離をどう作るかの **構造比較** を 3 案提示
  - 案 A: 全事業共通テンプレ + メインカラーのみ可変
  - 案 B: ヘッダー・フッターのみ共通、本文レイアウトは自由
  - 案 C: トップとコールセンター/AI OPS/財務 で完全に別世界観、フッターのみ共通
- それぞれのリスクと運用負荷を整理

### Priority 3 — 「顔出しなし」様式の選択肢比較
- 顔の代替表現を 5〜7 様式に整理:
  - 後ろ姿動画 / シルエット / イラスト / 手元・道具 / 環境ショット / 音声 + 文字 / アバター
- それぞれの実例 + 採用した時の制作負荷・更新負荷を比較
- 役員説明用に「**なぜこれがブランド資産になるか**」のロジックを文書化

### Priority 4 — KPI の再定義
- 上司・役員と擦り合わせる前提で、サイトの成功指標を再定義
- 候補: 滞在時間 / 事業ページへの遷移率 / 採用エントリー / 第一想起調査 / 問合せ単価
- これは数値設計が必要なので、**マーケ責任者がいれば巻き込み**

## 7. 私からの所感

打ち合わせで出た方向性は **戦略として筋が良い**。特に "顔出しなし × コールセンター起源 × 事業別トーン分け" の 3 点は、単独でも差別化材料だが、**3 つを連動させると独自のブランド世界観** になる。

ただし、これを成立させるには **構造設計（メタ層 / 事業層の分離）** と **代替信頼指標（数値・実績・取引先）** の 2 つを最初に固めないと、現場で「結局よくわからないサイト」に着地するリスクが大きい。

次の MTG ではリサーチを深めるよりも、**Priority 2（マルチブランド構造の設計案）を 1 枚で提示** して、上司・役員に「この構造で進める」という合意を取るのが最重要。構造が決まれば、その上に乗る素材・演出・トーンは後から肉付けできる。
