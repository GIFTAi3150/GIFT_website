## 1. 発注の前提条件

### 1.1 これは何のための発注書か

Phase B（マルチブランド構造）と Phase C（顔出しなし様式）で **構造と様式が確定** したので、その構造に **過不足なくはまる素材** を発注するためのドキュメント。

「先に素材を作ってから構成を考える」のではなく「**構成に合わせて素材を発注する**」というのが上司発言の方針:
> 「素材は最後はめ込む感じでむしろその構成に合わせた素材を最後用意するイメージで！」

### 1.2 KPI との整合

各素材は `07_kpi_redefinition.md` の 5 軸 KPI のどれに効くかを明記する:

- A: ブランド認知
- B: エンゲージメント
- C: 事業導線
- D: CV 質
- E: ベースライン

### 2.2 撮影発注書（カメラマン向け）

#### 全体ディレクション

- **トーン**: 静謐・知的・誠実。広告写真ではなく **編集メディア寄り**
- **色温度**: ニュートラル〜やや寒色寄り。人肌が出るカットがあれば標準
- **照明**: 自然光優先。人工照明はソフト
- **アングル**: ローアングル・俯瞰・対象を斜めから — 説明的にならず情景的に
- **被写界深度**: 浅め〜中程度。ピントを外して空気感を出す
- **顔の扱い**: 顔が映ってはならない（後ろ姿・シルエット・手元・環境のみ）

#### 納品形式

- RAW + 高解像度 JPEG（5000px 以上）
- WebP / AVIF へのコンバート可能な形式
- 商用利用権込み（**サイト掲載 + 採用パンフ + プレスリリース** 全て可）

#### 想定発注先

- 札幌のフォトグラファー（地域性を出す観点）
- 東京の建築・編集系フォトグラファー（クオリティ重視）
- ブランディング撮影実績のあるスタジオ

## 7. 発注スケジュール案

### 7.1 想定タイムライン

```
Week 1-2:  発注先候補リサーチ + 見積もり取得
Week 3:    発注先決定 + 契約
Week 4-6:  撮影・コピー執筆・イラスト制作・データ可視化制作
Week 7-8:  動画制作（撮影・編集）
Week 9-10: 全素材納品 + 開発担当への引き渡し
```

合計 **約 10 週間（2.5 ヶ月）**

### 7.2 並行発注の優先順位

並行発注で工数を圧縮するための順序:

1. **最初に**: タグライン（E-1）— 全体方向性が決まらないと他が進まない
2. **同時に**: コピー本文（E-2 / E-4）+ 写真撮影発注準備（A）
3. **タグライン確定後**: 動画ディレクション + イラスト発注
4. **最後に**: データ可視化（数値が確定してから）

| C. イラスト | 装飾イラストを社内 or 既存素材で対応 → -10〜20 万円 |
| D. データ可視化 | D-3（章立てヘッダー）を社内デザインで対応 → -5〜10 万円 |

## 9. 失敗パターンの予防

### 9.1 よくある失敗

| アンチパターン | 対策 |
| --- | --- |
| 安価なフリー素材で済ませる | 「無料っぽさ」が出る（上司の最重要懸念）。必ずプロ発注 |
| カメラマンを 1 日で全現場撮影 | クオリティ低下。現場ごとに別日にする |
| イラストレーターを複数人に分割発注 | タッチがバラついてブランド崩壊。1 名統一 |
| コピー発注で「短く強く」の指示を忘れる | 冗長な広告コピーになる |
| 動画制作で派手な BGM・テロップを許す | 上品さが損なわれる |

### 9.2 受け取り時のチェックリスト

各素材納品時に以下を確認:

- [ ] 顔が映っていない（顔出しなし方針）
- [ ] 解像度が要求を満たす
- [ ] 商用利用権が含まれる
- [ ] フォーマットが Web で使える
- [ ] 各事業のメインカラーと整合
- [ ] トーンが「数百万かけた感じ」に到達
