## 使い方

- 各サイトを **PCで実際に開いてスクロール** しながら見る
- 注目するポイント: **ヒーロー（最初の画面） / スクロール演出 / タイポと余白 / 事例の見せ方 / 配色**
- 上司には「**A/B/C のどれが一番近いか**」「**1つだけ選ぶならどれか**」「**絶対避けたいのはどれか**」を言ってもらう

## ミーティングでの確認フォーマット（メモ用）

ミーティング中に上司に聞きたい質問:

1. **A/B/C のどれが一番近い？**（複数 OK だが優先 1 つ）
2. **絶対避けたいのはどれ？**（除外条件を明確に）
3. **「これすごい」と思うサイトを 1 つ**（その場の感覚で）
4. **動きの強さ**: 弱い ←─（1〜10）─→ 強い どのあたり？
5. **写真主導 / イラスト主導 / 3D 主導 / 文字主導** どれが好み？
6. **「ウチとは違う」と感じる業界・テイスト**は？
7. **既存の GIFT サイト**（gift-inc.org）の **どこは残したいか / 変えたいか**

## 補足: 私（リサーチ担当）からの所感

GIFT の事業内容（コールセンター + DX + 財務コンサル、札幌本社、設立 2018）と「数百万かけた感じ」を素直に重ねると、**現実解は A をベースに B の編集感を一部取り入れる構成** です。理由:

- C（映像没入型）は B2B の意思決定者（経営層・財務責任者）に **過剰** に映りやすい
- A 単体だと SaaS スタートアップ感が強くなり、**コールセンター・財務コンサルの重厚さ** とミスマッチ
- B の編集感（写真・グリッド・余白）は、メンバー紹介・事例・社史の見せ方で効く

ただしこれはあくまで一意見であり、上司の好みが C 寄りなら方針を切り替えるべき。**上司の感覚を引き出すのが最優先**。
