## 0. 結論サマリ（先に読む）

打ち合わせで上司が共有した 2 サイト + 追加発掘 13 サイトを分析した結果、**「顔出しなし」の実装には 4 つの主要パターン** があることが判明:

1. **集合・数値で語る型**（Neu / CREAM / Whatever）— 個人を出さず、組織として数値・拠点・哲学で勝負
2. **環境・現場ショット型**（桐山組）— 人物の代わりに現場・空間を主役に
3. **インフォグラフィック型**（ALH 採用）— データで人物像を可視化
4. **イラスト化型**（バケモノ / Ra-tel / 講談社採用 / GEAR8 等）— 似顔絵で親しみと匿名性を両立

GIFT の場合は **(1) 集合・数値型 + (4) イラスト化型のハイブリッド**、コールセンター採用ページのみ **(2) 環境・現場ショット型** を採用するのが現実解と推測。

また、**rebita 20th** は「過去→現在→未来」の年表型ストーリーを「HISTORY → SOLUTION → CASE STUDY」で繰り返す構造で、上司が言う **「ストーリーテラー的演出」の実現方法** として強い参考になる。

## 1. neu-ad.jp 分析（上司共有参考 #1）

### 1.1 取得情報の制約

サイトが JS 主導で構築されているため、HTML 直接取得では映像・動画の構図・再生方式が確認できなかった。**実機ブラウザでの追加検証が必要**。

### 1.2 確認できた構造

| 項目 | 内容 |
| --- | --- |
| ヒーロー | 「広告に、こだわりと偏愛を」というテキスト主体のキャッチコピー |
| ヘッダーナビ | Top / About / Service / Team / News / Contact |
| ページ構成 | キャッチコピー → About → Service（3区分） → Team → News（3件） → Contact CTA → Footer |
| ステートメント | Mission / Vision / Value（行動規範6項目を番号付きで列挙） |
| Team ページ | 職位＋氏名のみ（写真情報は HTML 取得時点では未確認） |
| トーン | 「狂気と楽しさ」「愛とロジック」「泥臭いPDCA」— **情熱・偏愛 × 実績志向** のハイブリッド |
| 信頼性補完 | 「月間1万件CV 6ヶ月連続」「ASP年間売上2位 2年連続」等の **数値主体** |

### 1.3 GIFT への学び

- **コピーライティングの強さ**: 写真や動画より、まず **言葉で世界観を作る** ことが土台になる。「広告に、こだわりと偏愛を」のような **短く強い** 1 行が打ち出されていれば、その下のビジュアルは比較的シンプルでも成立する
- **実績数値で人物の不在を補う**: 顔出しせず数値で殴るのは GIFT が真似できる構造。コールセンターなら「累計通信回線開通数」「平均CV率」、AI OPS なら「導入企業数」「自動化工数」、財務なら「累計融資実行額」等
- **トーンが情緒的＋論理的のハイブリッド** という点は、GIFT のように「コールセンター × IT × 財務」と複数事業を抱える企業にとって、ブランド統合の観点で参考になる

### 1.4 要追加検証

実機ブラウザで以下を確認する必要あり:
- Team ページのメンバー写真の有無と、ある場合の表現（後ろ姿？シルエット？イラスト？動画？）
- ヒーローの背景動画 / アニメーションの有無
- スクロール演出の具体（パララックス？フェード？）

> 上司との次回打ち合わせ時に、**画面を一緒に見ながら確認** することを推奨。

## 2. rebita.co.jp/20th/ 分析（上司共有参考 #2）

### 2.1 サイトの性質

これは **コーポレートサイト本体ではなく 20 周年特設サイト**。期間限定・特設だからこそ通常より演出が強めで、コーポレート本体に丸ごと持ち込むと運用負荷が高い。**トップページや事業ページの一部演出** として参考にすべき。

### 2.2 構造

#### 2.2.1 ヒーロー
- 複数の画像チップ（hero_chip_01〜21）が **アニメーション的にスクロール表示**
- 中央に「**もう、20年。まだ、20年。**」のタグライン
- 下部に「SCROLL DOWN」を示唆

#### 2.2.2 章立て（ストーリー構造）

```
ナビゲーション（9項目）
↓
ヒーロー（画像チップ × タグライン）
↓
創立20周年ステートメント
↓
「もう、20年」セクション（2025の現在地）
↓
時系列8章（2005 → 2024）
  各章: HISTORY（市場環境） → SOLUTION（リビタの対応） → CASE STUDY（実例）
   ├─ 2005: 挑戦のはじまり
   ├─ 2006: シェア時代の到来
   ├─ 2009: 中古市場の高まり
   ├─ 2013: 循環型社会
   ├─ 2016: 都市から地方へ
   ├─ 2018: 働き方改革
   ├─ 2020: 投資市場の活性
   └─ 2024: 進化するリノベーション
↓
メッセージセクション（社員 + 外部関係者の声）
↓
クロージング「まだ訪れたことのない地域に...」
```

#### 2.2.3 要素別の見せ方

| 要素 | 役割 |
| --- | --- |
| hero_chip 画像群 | 「企業イメージの蓄積」を視覚化 |
| case_thumb 画像 | プロジェクト事例の視覚化 |
| intermission 画像（×16枚） | **セクション間の "視覚呼吸"**。リズムを作るための画像 |
| ロゴ・タグライン | 複数箇所で繰り返しブランド確認 |

#### 2.2.4 コピーの階層

- 最上位: **「もう、20年」「まだ、20年」**（サイト全体テーマ）
- セクション見出し: 年号 + タイトル（例: 「2005 / 挑戦のはじまり」）
- サブ見出し: 「（ HISTORY ）」「（ SOLUTION ）」「（ CASE STUDY ）」 ← 括弧と英語小文字で **誌面感**
- 本文: 80〜300字の短段落
- キャッチ: 「**新築でも中古でもない第三の選択肢**」など引用符で強調

### 2.3 GIFT への学び（最重要）

#### A. 「対比の冒頭」テンプレ
**「もう、20年。まだ、20年。」** のように、**達成と志を対比** させる短いタグラインは強い。GIFT が打ち出すなら例:

> 「もう、コールセンター。まだ、コールセンター。」
> 「すべての電話の向こうに。これからも、その先に。」
> 「Gift an opportunity — 7年。これから、未来へ。」

#### B. 「市場環境 → 自社解 → 実例」の3層繰り返し
各セクションで `HISTORY → SOLUTION → CASE STUDY` を繰り返す構造は、**事業説明ページの章立てとして直接転用できる**。

GIFT の事業ページに当てはめると:

```
[事業: コールセンター]
  ↓
HISTORY: 通信業界の課題（営業効率の限界、顧客接点の希薄化）
  ↓
SOLUTION: GIFT のアプローチ（自社運営×教育主導×アウトバウンド特化）
  ↓
CASE STUDY: 実績数値 + 取引先カテゴリ
```

これを **コールセンター / AI OPS / 財務 の各事業ページで繰り返す** と、サイト全体に統一感とリズムが生まれる。

#### C. ストーリーテラーの仕掛け
- **章と章の間に "intermission 画像"** を入れる手法は、退屈を防ぐ巧妙な設計
- GIFT 版に置き換えると、章の間に **"事業横断の風景写真" や "数値タイポグラフィ"** を挟むことで、長いトップページでも飽きない構成にできる

#### D. 「多声性」で立体化
- 社員の声 + 外部関係者の声の **両方** を載せている → "客観性" と "信頼" を同時に獲得
- GIFT 版なら **取引先の推薦コメント、応募者の声、メンバーのテキストインタビュー** などで補完できる

### 2.4 適用範囲の制約

これは **20 周年特設という期間限定文脈** だからこそ成立している演出が多い。コーポレート本体に持ち込む場合:

- 章数を **2〜3 章** に削る（rebita は 8 章だが時系列前提なので成立）
- intermission 画像は採用しても枚数を抑える（更新コスト）
- 多声性は **採用ページや事例ページに限定** して使う

### 3.2 様式別の評価

| 様式 | 採用事例数 | 制作負荷 | 更新負荷 | GIFT 適用可能性 |
| --- | --- | --- | --- | --- |
| **集合・数値で語る** | 4件（Neu / CREAM / Whatever / ALH） | 低（撮影不要） | 低 | ◎ AI OPS事業の信頼性補完に最適 |
| **環境・現場ショット** | 1件（桐山組） | 中（撮影必要） | 低 | ◎ コールセンター採用ページに最適 |
| **イラスト化** | 6件（バケモノ / くまweb / GEAR8 / Ra-tel / イイ人 / 講談社） | 中（イラスト発注） | 中（メンバー追加時） | ◯ メンバーページの主軸候補 |
| **シルエットアイコン** | 1件（rebita 20th 外部関係者） | 低 | 低 | ◯ 取引先の推薦コメント等で活用可 |
| **後ろ姿動画 / 手元動画** | **未確認**（国内事例で公開情報範囲では特定できず） | 高（動画撮影） | 高（メンバー変更で再撮影） | △ 上司の好みだが運用負荷が高い |
| **アバター / ゲーム化** | 1件（みずほFG） | 高 | 中 | △ B2B コーポレートには軽すぎる可能性 |

### 3.3 重要観察

1. **「完全に顔を出さない」を貫いている事例は少数派**（Neu / CREAM / Whatever / 桐山組 / ALH の 5 件）。多くは **イラスト化** で「親しみは出すが個人特定はしない」という妥協点を取っている
2. **動画主役の「後ろ姿で歩く / 手元で作業」型の国内 B2B 事例は今回未確認**。上司が neu-ad.jp の team で「動画にすると品質高い感じがする」と言っていたが、これは neu-ad のサイト全体トーンから来る印象で、明示的な動画チーム紹介ではない可能性が高い
3. **信頼性補完の共通パターン 4 つ**:
   - 実績数値（最も多い）
   - 第三者評価・受賞
   - 拠点数・規模・歴史
   - 同僚コメント / 外部推薦

## 4. Phase B（マルチブランド構造）への持ち込み素材

### 4.1 メタ層 vs 事業層の分離 — 推奨設計

rebita 20th の章立て構造（HISTORY → SOLUTION → CASE STUDY）と、Neu の数値主導コピーを組み合わせると、以下の枠組みが見える:

```
[メタ層: 全事業共通]
  - グローバルナビ・フッター
  - タイポ規則（見出しの英語小文字 + 括弧などの誌面感ルール）
  - 「対比の冒頭」テンプレ
  - 数値を主役にする情報設計
  - 顔出しなしの表現様式（後述）

[事業層: 各事業で可変]
  - メインカラー（AI OPS: テック青、コールセンター: 別色、財務: 別色）
  - 章ごとのモチーフ画像（intermission 的な視覚呼吸）
  - 動画・画像のトーン（コールセンター: 現場ショット / AI OPS: データ可視化 / 財務: 静謐な編集感）
```

### 4.2 「顔出しなし」のハイブリッド推奨

| ページ | 推奨様式 | 理由 |
| --- | --- | --- |
| トップ | 数値タイポグラフィ + 環境ショット | 「集合で語る」 |
| AI OPS | 数値 + データインフォグラフィック | 信頼性最優先 |
| 財務コンサル | 環境ショット + 第三者推薦コメント | 重厚・静謐 |
| コールセンター（採用兼） | **環境ショット（オフィス・現場）** + 入社者コメント | 桐山組型。採用効果を優先するなら **顔出し OK の例外設計** も検討 |
| メンバー一覧 | **イラスト化** + テキストインタビュー | 親しみと匿名性のバランス |

### 4.3 ストーリーテラー演出の最小実装

rebita のような大規模演出は予算的に厳しいので、**最小コアだけ移植** する案:

1. トップヒーローに **「対比の1行」タグライン**（3〜5案を Phase D の素材発注で言葉として発注）
2. トップに **3章構成**（コールセンター → AI OPS → 財務）を入れ、各章で **HISTORY / SOLUTION / CASE** を 1 セットだけ提示
3. 各章の最後に **その事業の専用ページへの導線**（次章への引き込み）
4. 章と章の間に **数値タイポグラフィ または 環境写真 1 枚** を挟んで視覚呼吸を作る

これだけで「ストーリーテラー型」の感触は出せる。フル動画演出は AI OPS 事業ページ等、ページ単位で導入する。
