## 0. 役員向けエグゼクティブサマリ

### なぜ KPI 再定義が必要か
今回のリブランドでは「**尖った構成・顔出しなし・ストーリーテラー型**」を採用するため、従来の「**問合せ件数 / 採用エントリー数**」だけで評価すると、**短期的に下がる可能性**がある。下がっても、それが失敗とは限らない。**評価軸を変えないと、せっかくの戦略を中途半端に否定することになる**。

### 推奨 KPI セット（5 軸）

| 軸 | 主要指標 | 目的 |
| --- | --- | --- |
| **A. ブランド認知** | 第一想起 / 検索流入 / 直接流入比率 | 「GIFT といえば〜」の地位獲得 |
| **B. エンゲージメント** | 平均セッション時間 / スクロール深度 / 動画再生率 | ストーリーテラー構造の効果 |
| **C. 事業導線** | 事業ページ遷移率 / 事業横断回遊率 | マルチブランド構造の効果 |
| **D. CV 質** | 問合せ単価 / 採用応募の質 / マッチ率 | 「数」より「質」 |
| **E. ベースライン** | 問合せ件数 / 採用エントリー / 直帰率 | 従来 KPI（下限ライン監視） |

### 推奨方針
**A〜D を主指標、E は下限監視**。リブランド後 6 ヶ月は **「下がっても構わないが、下がりすぎないか」** を E で監視。半年後にデータで判断。

### リスクと対策
- **リスク**: 役員が短期的な問合せ件数の低下に反応して施策を巻き戻す
- **対策**: 本ドキュメントで **「下がる可能性 + その意味」** を事前に役員合意。半年データを見るまで判断しない約束を取る

### 次のステップ
1. 役員レビューで KPI セット合意
2. ベースライン測定（リブランド前の数値を控える）
3. 計測ツールの整備（GA4 + Microsoft Clarity は実装済み）

## 2. なぜ既存 KPI だけでは不十分か

### 2.1 既存 KPI の限界

| 既存 KPI | 限界 |
| --- | --- |
| 問合せ件数 | 「尖った」サイトは、最初は問合せが減る可能性。減ったから失敗ではない |
| 採用エントリー数 | 顔出しなしの効果は半年〜1年遅れて出る |
| PV / UU | 流入総量は SEO 施策に依存。ブランド再構築の効果は出にくい |
| 直帰率 | ストーリーテラー型ではむしろ滞在を望むので、直帰率より「滞在の深さ」が重要 |

### 2.2 「尖った」サイトの効果は遅れて出る

|  時期 | 既存 KPI | 新 KPI |
| --- | --- | --- |
| 0〜1ヶ月 | 下がる可能性大 | エンゲージメント指標が上昇 |
| 1〜3ヶ月 | やや回復 | ブランド検索（指名検索）が増加 |
| 3〜6ヶ月 | 回復〜微増 | 質の高い問合せ単価が上昇 |
| 6ヶ月〜 | 増加軌道 | 第一想起・採用ブランド認知 |

→ **既存 KPI だけ見ていると、3 ヶ月時点で「失敗」と判定してしまう**。新 KPI で全体を見る必要あり。

## 3. 推奨 KPI セット（5 軸詳細）

### 3.1 軸 A: ブランド認知

**「GIFT といえば〜」の地位を作れているかを測る**

| 指標 | 計測方法 | 目標 |
| --- | --- | --- |
| 指名検索数（"株式会社GIFT" "GIFT 札幌" 等） | Google Search Console | 半年で +50% |
| 直接流入比率 | GA4 / Direct Traffic | 半年で +20% |
| ブランド検索からの流入の問合せ転換率 | GA4 / Source = direct or organic + brand keyword | 数値ベースライン化 |
| 第一想起調査（半期） | アンケート（取引先・採用候補者） | 質的評価 |

### 3.2 軸 B: エンゲージメント

**ストーリーテラー型構成が効いているかを測る**

| 指標 | 計測方法 | 目標 |
| --- | --- | --- |
| 平均セッション時間 | GA4 | リブランド前比 +30% |
| 平均スクロール深度（トップ・事業ページ） | GA4 + Clarity | 75%以上が標準ライン |
| 動画再生完了率（Hero 動画） | GA4 カスタムイベント | 30%以上 |
| 事業ページの章ごとの読了率 | Clarity ヒートマップ | 各章 60%以上 |

### 3.3 軸 C: 事業導線

**マルチブランド構造（メタ層 / 事業層）が機能しているかを測る**

| 指標 | 計測方法 | 目標 |
| --- | --- | --- |
| トップから事業ページへの遷移率 | GA4 イベント | 40%以上 |
| 事業ページ間の横断回遊率（コール → AI / AI → 財務 等） | GA4 ファネル | 15%以上 |
| メンバーページから事業ページへの遷移率 | GA4 イベント | 25%以上 |
| 平均閲覧ページ数 | GA4 | 3 ページ以上 |

### 3.4 軸 D: CV 質

**「数より質」を測る**

| 指標 | 計測方法 | 目標 |
| --- | --- | --- |
| 問合せの平均単価（受注額 / 問合せ数） | 受注 CRM × GA4 | リブランド前比 +30% |
| 問合せの業界カテゴリ分布 | 問合せフォームの種別ログ | 高単価業界の比率増加 |
| 採用応募者のマッチ率（書類通過率 等） | 採用 CRM | 半年で書類通過率 +10pt |
| 問合せ → 受注のリードタイム | 受注 CRM | 短縮傾向 |

### 3.5 軸 E: ベースライン（下限監視）

**致命的な悪化を検知する**

| 指標 | 計測方法 | アラートライン |
| --- | --- | --- |
| 月間問合せ件数 | フォーム送信ログ | 前年同月比 -30% で要レビュー |
| 月間採用エントリー数 | 採用フォーム | 前年同月比 -40% で要レビュー |
| 直帰率 | GA4 | 80% 超で要調査 |
| ページロード時間（LCP） | GA4 + PageSpeed Insights | 4 秒超で要対応 |

## 4. 計測実装プラン（開発担当への申し送り）

### 4.1 既存 GA4 にカスタムイベントを追加

リサーチ側で要件を出し、開発担当が実装する想定:

| イベント名 | 発火タイミング | 用途 |
| --- | --- | --- |
| `hero_video_play` | Hero 動画再生開始 | 動画到達率 |
| `hero_video_complete` | Hero 動画完了 | 動画完了率 |
| `chapter_scroll_75` | 各章の 75% スクロール | 読了率 |
| `business_page_view` | 事業ページ表示 | 事業導線 |
| `member_to_business_click` | メンバーページから事業ページへの導線クリック | 事業導線 |
| `cta_click_inquiry` | 問合せ CTA クリック | CV ファネル |
| `cta_click_recruit` | 採用 CTA クリック | 採用ファネル |

### 4.2 Clarity の活用

- ヒートマップ: 事業ページの章ごとに分析
- セッション録画: 上位流入経路の代表セッションをサンプリングで定性分析
- ラージプレビュー: 動画 / イラストの実際の見え方確認

### 4.3 ベースライン測定

リブランド実装着手 **前** に以下のベースラインを測定する必要あり:

- 過去 3 ヶ月の各既存 KPI
- 流入元別の比率（Direct / Organic / Social / Referral）
- ページ別の滞在時間
- 問合せの業界カテゴリ分布

## 5. ダッシュボード設計（提案）

### 5.1 月次レビュー用ダッシュボード

5 軸 × 月別推移を 1 枚で見れる構成:

```
┌─ A. ブランド認知 ─┐  ┌─ B. エンゲージメント ─┐
│ 指名検索数         │  │ 平均セッション時間     │
│ 直接流入比率       │  │ スクロール深度         │

┌─ C. 事業導線 ─┐  ┌─ D. CV 質 ─┐

│ 横断回遊率     │  │ 採用マッチ率    │
```

### 5.2 役員報告用フォーマット

四半期ごとに役員に提出する想定:

- A〜D の主要指標を **前期比 / 前年比 / リブランド前比** で表示
- E はアラートとして「正常 / 要観察 / 要対応」の 3 段階
- 質的評価（第一想起調査結果、Clarity セッション分析サマリ）を 1 ページ

## 7. 失敗パターンの予防

### 7.1 やってはいけないこと

| アンチパターン | リスク |
| --- | --- |
| 1〜3 ヶ月で問合せ件数の悪化を理由に施策を巻き戻す | 戦略の中途半端な否定 |
| KPI を毎月変えてしまう | 比較不能、判断軸の喪失 |
| ベースライン測定を省略 | 効果検証ができない |
| 質的評価（第一想起調査・Clarity 分析）を後回しにする | 数値だけでは見えないブランド変化を見落とす |

### 7.2 半年は数値を「観察」する期間

リブランド後の最初の 6 ヶ月は **判断を急がない** 期間として位置付ける。

- 月次レビューは行うが、施策変更は **データの傾向が確定してから**
- 既存 KPI（E）が **アラートライン突破** した場合のみ即時対応
- 6 ヶ月時点で **総合判定**
