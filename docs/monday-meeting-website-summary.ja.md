# Webサイト — 月曜MTG 報告サマリ

## 概要
GIFT Incの旧WordPressサイトを、**Next.js + TypeScript + Tailwind + Vercel** の構成でゼロから作り直し中。あわせてサイト全体を会社の主力である **「AIOps」軸** に再構成しています。

## 現在の状況
- 新サイトは **すでに公開稼働中** → `aiops.gift-inc.org`。旧WordPressサイトと **並行稼働・無停止**。
- 主要ページ実装済み：トップ / AIOps / 会社紹介 / お問い合わせ / DX / 404。お問い合わせフォームも稼働中。
- 日々の修正は `dev` ブランチ経由で公開反映（Vercel自動デプロイ）。

## 今回のメイン論点（先週起きたこと）
先週、ドメインのDNSをVercelに向けたところ不具合が発生。**旧サイトにダッシュボードや他のシステムが紐づいて**おり、それらは簡単には移せないためです。

**完全移行（マイグレーション）** は複雑でリスクが高いと判明したため、**リダイレクト方式** に切り替えました：
- 圧倒的にシンプル。
- 旧サイト側（ダッシュボード・ブログ・API等）には **一切手を触れない**。
- 旧サイトの訪問者を新サイトへ **リダイレクトするだけ**。

現在このプランを **マネージャーに提出し、Go/No-Go待ち**。それまでDNSは凍結中。

## その他のブロッカー
- Vercelの組織アカウント接続 … マネージャーのOwner権限付与待ち。
- 会社紹介ページの具体数値（社員数など）… 役員確認が取れるまで抽象表現のまま。

## 今後（次フェーズ）
現在 **非表示にしているページ（コールセンター等）** があり、**次バージョンに含めるかどうかの確認待ち** です。
