## ゴール

上司の打ち合わせアウトプット（`request260430.md`）を起点に、**「数百万かけたサイト」水準のクオリティ刷新** を進めるための判断材料を、フェーズごとに整える。

実装着手の前に **構造合意（マルチブランド構造）** と **表現様式合意（顔出しなし様式）** を確定させ、素材発注は構造確定後に行う方針。

---

## フェーズ構成

```
Phase A — 参考サイト深掘り
  ↓（具体イメージの解像度を上げる）
Phase B — マルチブランド構造の設計案
  ↓（構造を確定 → 役員合意取得）
Phase C — 「顔出しなし」表現様式の比較
  ↓（表現様式を確定）
Phase D — KPI 再定義 + 素材発注書
  ↓（成功指標と素材を確定）
[実装着手は別ブランチ・別担当]
```

各フェーズの成果物は `docs/research/` 配下に Markdown で蓄積する。

## Phase A — 参考サイト深掘り

### 目的
上司・役員が「これくらいのクオリティ」「この動きが好き」と **具体例で合意できる粒度** までリファレンスを分析する。

### 対象
1. **`https://neu-ad.jp/` のチーム紹介** — 上司が最も具体的にイメージしている参照
2. **`https://www.rebita.co.jp/20th/`** — 周年特設サイト系の演出
3. **追加発掘 5〜10 サイト** — "顔出しなし B2B / クリエイティブ系コーポレート"

### 成果物
- `docs/research/04_reference_deep_dive.md`
  - 各サイトの **ヒーロー / スクロール演出 / モーション / 動画仕様 / タイポ / 配色** をスクショ + コメントで分析
  - neu-ad.jp は **動画の長さ・構図（後ろ姿/手元/環境）・解像度・再生方式（autoplay/loop/muted）** まで分解
  - rebita 20th は **章立て構造とスクロール体験** を時系列に書き出し
  - 追加発掘サイトは "顔出しなし" の様式別に分類

### 完了条件
- 上司との打ち合わせで「**この動き / この構成 / この粒度**」を指で示せる状態になる
- 次フェーズ（B）の設計案に入れる素材 / 演出のヒントが3〜5個以上抽出できている

### 想定工数
2〜3 日（リサーチ集中作業）

## Phase B — マルチブランド構造の設計案

### 目的
**事業別にトーンが違うが、同一企業のサイトに見える** 構造を設計する。  
役員に「この構造で進める」という合意を取得する。

### 検討する 3 構造案

| 案 | 構造 | 共通要素 | 可変要素 | リスク |
| --- | --- | --- | --- | --- |
| 案 A: テンプレ型 | 全事業共通テンプレ | レイアウト全般 | メインカラーのみ | 退屈になる |
| 案 B: 中庸型 | ヘッダー/フッター共通、本文自由 | ナビ・タイポ・グリッド | 写真トーン・モーション | 設計の難度が中 |
| 案 C: 分断型 | トップ/各事業で完全別世界観 | フッターのみ | ほぼ全部 | ブランド一貫性崩壊リスク |

### 成果物
- `docs/research/05_multibrand_structure.md`
  - 3 案の構造比較表（メタ層 vs 事業層の分離レベル）
  - 各案の運用負荷・実装難度・更新フロー
  - 推奨案 + その理由
  - 役員説明用 1 枚資料（PDF 出力可能な構成）

### 完了条件
- 上司・役員に **構造案 1 つを選んでもらう** ところまで持ち込める
- 選定後、Phase A で見つけた参考サイトの演出を **どの層** に乗せるかが決まっている

### 想定工数
3〜4 日

### 重要
このフェーズでサイト全体の骨格が決まる。**ここで合意を取り損ねると、後段の表現議論が空中戦になる**。

## Phase C — 「顔出しなし」表現様式の比較

### 目的
顔の代わりにメンバーや会社らしさを伝える **表現様式** を 5〜7 案で比較。  
役員から「これでいく」を取得する。

### 検討する様式

| 様式 | 実例 | 制作負荷 | 更新負荷 | 雰囲気 |
| --- | --- | --- | --- | --- |
| 後ろ姿動画 | neu-ad.jp 等 | 中（撮影必要） | 高（メンバー変更で再撮影） | クール・洗練 |
| シルエット | （要発掘） | 低 | 低 | ミニマル・洗練 |
| イラスト（人物） | （要発掘） | 中（イラスト発注） | 中 | 親しみ・ブランド化しやすい |
| 手元・道具ショット | （要発掘） | 中 | 低 | 職人的・本質志向 |
| 環境ショット（オフィス・現場） | （要発掘） | 低 | 低 | リアル・ドキュメンタリー感 |
| 音声 + 文字（顔なしインタビュー） | （要発掘） | 中（収録必要） | 中 | 文学的・編集感 |
| アバター / アイコン | （要発掘） | 中 | 低 | テック寄り・遊び心 |

### 成果物
- `docs/research/06_faceless_styles.md`
  - 各様式の実例（スクショ）+ 制作 / 更新コスト
  - 信頼性補完戦略（顔の代わりに何を見せるか — 数値・実績・第三者ロゴ）
  - 推奨様式 + コールセンター採用ページの例外検討
  - 役員説明用ロジック（「なぜこれがブランド資産になるか」）

### 完了条件
- 様式 1 つ（または組み合わせ）に絞り込まれている
- 「コールセンター採用ページだけ顔出し OK」等の **例外設計** も合意されている

### 想定工数
2〜3 日

## Phase D — KPI 再定義 + 素材発注書

### 目的
構造と表現が決まった上で、**成功指標** と **発注すべき素材** を確定する。  
構造に合わせた素材を発注できる状態にして、開発担当に引き渡す。

### D-1: KPI 再定義
- 既存サイトの目的: コーポレート紹介 / 採用 / 問合せ獲得 のどれが主か再確認
- 「尖った」サイトに合わせた評価軸への切り替え検討:
  - **滞在時間 / セッションの深さ**（ストーリーテラー型の評価）
  - **事業ページへの遷移率**（トップから引き込む構成の評価）
  - **採用エントリー数**（コールセンター採用ページの評価）
  - **第一想起調査**（ブランド認知の評価）
  - **問合せ単価**（"質の高い問合せ" を評価）
- 役員間で合意取得

### D-2: 素材発注書
- Phase B/C で確定した構造・様式に **必要な素材リスト**:
  - 動画カット（ヒーロー用 / セクション切替用 / メンバー紹介用 — 各長さ・構図指定）
  - 写真撮影リスト（オフィス / 現場 / 手元 等）
  - イラスト発注リスト（人物代替・装飾モチーフ等）
  - コピーライティングリスト（事業ページの章立てに沿った見出し・本文）
- 各素材の発注先候補（カメラマン / 動画制作会社 / イラストレーター / コピーライター）
- 予算配分案

### 成果物
- `docs/research/07_kpi_redefinition.md`
- `docs/research/08_asset_brief.md`

### 完了条件
- KPI が役員合意済み
- 素材発注書が、外部発注先に **そのまま投げられる粒度** で完成している
- 開発担当に引き渡しできる状態

### 想定工数
3〜4 日
